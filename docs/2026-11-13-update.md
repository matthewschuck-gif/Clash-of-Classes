## Squad event check-ins (26_CheckIns.gs): how Gym 1 is won
- Sign-up Events gets a **Kind** column (Move, Make, Talk).
- An event with a Kind and a Date opens for check-in that day plus `CHECKIN_DAYS` (default 1).
- **Students** check in with their 800# from a card on the home page and My Squad.
- **Generals** confirm or remove each one in **Generals HQ › Check-ins**. The tab shows how many are
  waiting, and Generals can add a member who forgot.
- Only confirmed check-ins count (Event Check-ins tab).
- Gym 1 = confirmed participants last month + points from events typed `squad_move`, `squad_make`,
  `squad_talk`.
- Admin › Add Event and Bulk Entry now have a Type picker: Squad event Move / Make / Talk, Staff squad
  challenge winner (Front Office), and Pride Day (Gym 2 stopgap).
- Pride Day: Climb-er's `pride_day` (% of the squad). Until it sends one, Pride Day rows decide Gym 2.

## Edit or override any piece
| Piece | Where to change it | Override |
|---|---|---|
| Zone rules, Multiplier, weekly points, holder | Admin › Map (or Conquest Rules / Map Zones tabs) | **🔒 Lock holder**: nothing moves it automatically (Map Zones › Locked) |
| A squad's number for a zone | Admin › Map › click the zone › **Override [month]'s numbers** | Saved on the **Zone Overrides** tab; newest row wins, a blank clears it. Saving re-checks holders right away. |
| Climb-er's monthly numbers | Squad Monthly tab | Use a zone override if Climb-er's next sync would overwrite your fix |
| Squad event check-ins | Generals HQ › Check-ins, or the Event Check-ins tab (Confirmed tick) | Untick Confirmed or delete the row |
| Freezes and thaws | Point Freezes tab; Settings › FRESH_START | Staff Sign-off, End date, Thawed |
| Pulse questions | Daily Polls and Poll Ideas tabs | Show unticked hides one; edit Through to close early |

## Admin password
- Set it from the Sheet: **Clash of Classes › Set admin password…**.
- Or set it on the site: **Admin › Settings › New Admin Password**.
- It is stored only as a salted hash in Script Properties. It is never in this repo.

## Pulse (06_Polls.gs)
- New Kind `Pulse`:

  - results show live right after a vote
  - open Date through Through (new column)
